# O Segredo da Floresta — Aventura Interativa

Projeto desenvolvido com HTML, CSS e JavaScript para praticar estruturação de páginas, atributos HTML, estilização e manipulação do DOM.

## Como executar
1. Baixe ou extraia os arquivos desta pasta.
2. Abra o arquivo `index.html` em um navegador.
3. Toque em **Começar aventura** e escolha os caminhos da história.

## Arquivos
- `index.html`: estrutura e conteúdo da página.
- `style.css`: cores, layout, responsividade e efeitos visuais.
- `script.js`: cenas, escolhas e interações da aventura.

## Conceitos praticados
- Tags semânticas HTML (`header`, `main`, `section`, `footer`).
- Atributos `id`, `class`, `data-*` e atributos de acessibilidade.
- CSS com classes, responsividade e estados de interação.
- Manipulação do DOM (`querySelector`, `createElement`, `textContent`, `classList`).
- Eventos com `addEventListener`.
- Laço `forEach` para criar e configurar elementos.
- História com caminhos e finais diferentes.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie os três arquivos (`index.html`, `style.css` e `script.js`) e, se quiser, o `README.md`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois toque em **Save**.
6. Aguarde a publicação e abra o endereço mostrado na seção Pages.
